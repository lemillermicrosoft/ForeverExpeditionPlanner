# Changelog

## 0.2.0-rc1 - 2026-09-30

- Added mandatory per-record provenance and an explicit zero-coverage official/public source manifest.
- Added safe `FEPX1` import/export and SavedVariables migrations through schema 4.
- Replaced partial party updates with atomic, versioned FEP2 transactions and bounded messages.
- Added dungeon/travel readiness templates, richer manual summaries, and optional integration detection.
- Added provenance tooltips, a Transfer page, deterministic protocol/migration/conflict validators, and package-content checks.
- Removed developer sample objects so fixtures cannot be mistaken for a real catalog.
- Kept Blizzard/native as the fresh-install default and retained Bronze as optional.

## 0.1.0-alpha

- Initial installable planner shell and Interface 16001 UI compatibility fixes.
